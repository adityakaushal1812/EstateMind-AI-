# 🏡 EstateMind AI

EstateMind AI is an AI-powered real estate intelligence project designed to analyze property-related data and extract meaningful insights.  
The system uses a structured dataset as the core input, which is utilized to train and evaluate the model for accurate analysis.

## 🚀 Features
- AI-based real estate data analysis  
- Dataset-driven model training  
- Insight generation from property data  
- Beginner-friendly and scalable project structure  

## 🧠 Technologies Used
- Python  
- Machine Learning  
- Pandas & NumPy  
- Scikit-learn  
- VS Code  

## 📊 Dataset
The dataset used in this project plays a crucial role in training the model.  
All predictions and insights are generated based on patterns learned from the provided dataset.
